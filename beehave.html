LLM style guide

1. Compose

Start with the app shell. Group controls inside .mc-panel; use .mc-card for dark content blocks.

2. Reuse

Use existing buttons, fields, tags, slots, alerts, tabs, progress bars, console, modal, and toast patterns.

3. Preserve

Keep square corners, hard shadows, 4px borders, pixelated images, accessible labels, and responsive breakpoints.
